# 청소년 유해 오디오 탐지 연구: 최종 요약

## 1. 연구 배경

청소년은 영상·음악·게임·숏폼 등 다양한 매체에서 폭력음, 욕설, 위협 발화에 노출될 수 있다. 화면을 지속적으로 분석하는 방식은 개인정보와 전력 사용 측면에서 부담이 크다. 따라서 본 연구는 **오디오만을 이용해 위험 가능성이 있는 구간을 먼저 좁히고, 필요한 때에만 더 무거운 판단을 수행하는 구조**를 설계했다.

## 2. 연구 목표

스마트폰 재생음 또는 마이크 오디오에서 청소년에게 유해할 가능성이 있는 음향·언어 신호를 실시간 탐지하고, 온디바이스 모델과 서버 모델을 단계적으로 실행해 개인정보 수집과 연산 부담을 줄이는 것이 목표다.

본 시스템은 유해매체물을 법적으로 확정하지 않는다. 총성·비명·위협·비속어처럼 위험 가능성을 나타내는 신호를 탐지하고, 맥락이 필요한 구간에 한하여 3층 서버가 유해 정도와 근거를 보조적으로 제시한다.

## 3. 최종 구조

```text
입력 오디오
 ├─ 1층: 상시 게이트(TinyMelCNN) — 재생 상태·후보 구간 관리
 └─ 2층: CED-mini INT8 — 폭력음·비명·총성 등 음향 위험 신호
           Demucs vocal 분리 → Whisper Base ONNX → KoELECTRA + 유해 표현 사전
                         └─ 음향 또는 언어가 의심일 때만
                              3층: Qwen2.5-Omni 서버 — 소리·전사·사건 정보를 종합
```

음향 경로는 원음을 유지해 총성·충돌음 등의 정보를 보존한다. 언어 경로는 보컬 분리 결과를 사용해 영화·음악의 배경 반주와 잡음이 ASR에 주는 영향을 낮춘다.

## 4. 핵심 연구 과정과 선택 근거

### 음향 모델

처음부터 학습한 작은 CNN은 약한 라벨 음향 자료에서 폭력음 정밀 탐지에 한계가 있었다. 사전학습 BEATs는 폭력 mAP를 0.228에서 0.746으로 높였지만, 모바일 탑재에는 무거웠다. 여러 경량 후보를 비교한 뒤 **CED-mini INT8**을 음향 트리거로 선택했다. 개발 평가에서 AP 0.834, Recall@FPR10 0.862를 보였고 모델은 약 10 MB다.

### 언어 경로

영화·음악에서는 배경 반주와 무음 구간 때문에 ASR이 반복 문자열이나 부정확한 단어를 만들 수 있었다. 실제 발화의 반복을 단순 삭제하면 위험 발화까지 지울 수 있어 채택하지 않았다. 대신 **음성 분리 → 무음 구간 제거 → Whisper Base**의 순서로 전사 입력을 정리했다.

KoELECTRA-small은 깨끗한 문장만이 아니라 ASR 오류·은어가 섞인 문장을 포함해 재학습했다. CER 20 조건에서 유해 발화 재현율은 0.416에서 0.803으로 향상됐다. 다만 오인식이 심하면 텍스트 분류도 완전할 수 없으므로, 음향 점수와 유해 표현 사전을 함께 사용하고 최종 맥락 판단은 서버로 넘긴다.

### 사건 단위 판단과 서버

서로 겹치는 4초 창을 하나의 HarmEvent로 묶어 같은 상황을 반복 전송하지 않도록 했다. 사용자가 선택한 경우에만 의심 구간의 오디오와 전사·점수를 서버로 보낸다. Qwen2.5-Omni는 오디오와 텍스트를 함께 받아 유해 정도·유형·근거를 반환하도록 설계했다. 현재 확인된 것은 사설망 연결과 `/health` 상태이며, Qwen 판단 품질의 대규모 평가는 후속 과제다.

## 5. Android ONNX 실측

Android 기준 조합은 정확도를 우선해 FP32 Demucs와 Whisper Base 원본 ONNX를 사용했다. 한 실기기에서 새 4초 입력을 처리했을 때 다음 결과를 얻었다.

| 항목 | 측정값 |
| --- | ---: |
| Demucs 보컬 분리 | 약 670 ms |
| Whisper Base 30초 입력 형식 ASR | 약 1,528 ms |
| 새 4초 전체 처리 | 약 2,198 ms |
| RTF | **0.550** |

RTF가 1보다 작으므로 이 조건에서는 4초 입력보다 빠르게 결과를 만들었다. 단, 이는 한 기기의 짧은 기능 시험이다. 배터리·발열·화면 상태·기기별 NPU/GPU 차이를 포함한 장시간 평가는 아직 수행하지 않았다.

## 6. 결론과 한계

본 연구는 단일 초대형 모델을 계속 실행하는 대신, 음향·언어·서버 판단을 단계적으로 연결했다. 실제 Android 기기에서 Demucs와 Whisper Base ONNX의 동작 및 RTF 0.550을 확인해, 정확도를 우선한 조합도 실시간 후보가 될 수 있음을 보였다.

남은 과제는 세 가지다.

1. 독립적인 강한 라벨 자료에서 음향·언어·사건 단위 성능을 검증한다.
2. Android와 데스크톱의 tokenizer·전처리·판정 결과를 golden audio로 동등성 검증한다.
3. 장시간 실행에서 배터리·발열·지연과 Qwen의 맥락 판단 품질을 평가한다.

따라서 이 결과는 청소년 보호를 위한 연구용 위험 신호 탐지기이며, 법률적 최종 판정 또는 보호자 개입을 자동화하는 도구로 사용해서는 안 된다.
