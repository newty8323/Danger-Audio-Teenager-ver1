# 연구 기록

이 폴더는 삼휴텍 논문대회 연구 과정을 재현 가능하게 기록한다. 원음·개인정보·대형 모델 가중치는 올리지 않고, 허가된 출처의 링크·통계·실험 설정·집계 결과만 기록한다.

## 권장 구성

1. `01-background.md` — 연구 배경과 문제 정의
2. `02-goals.md` — 연구 목표와 연구 질문
3. `03-prior-work.md` — 이론적 배경 및 선행연구
4. `04-method.md` — 1·2·3층 파이프라인과 구현·실험 과정
5. `05-results.md` — 데이터셋, 측정 조건, 정량·정성 결과와 한계
6. `benchmarks/` — 기기·모델·실행 조건별 JSONL 요약과 표

각 결과에는 날짜, 코드 커밋 ID, 기기 모델, 전원·화면 상태, 입력 길이, RTF, 오류 사례를 함께 적는다. 녹음 원본이나 식별 가능한 대사는 올리지 않는다.
